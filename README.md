# NeuralCanvas

NeuralCanvas 是一个面向学习、决策与行动执行的安卓认知图谱应用。  
它不只是普通思维导图，而是一个结合 **节点网络 + AI 助手 + 科学工作流模板** 的个人认知操作系统。

你可以用它来：

- 搭建知识网络
- 管理任务与目标
- 做科学决策
- 做每日 / 每周复盘
- 做检索练习与迁移练习
- 让 AI 读取图谱并辅助补全结构

---

## 核心定位

NeuralCanvas 的目标不是“画得更花”，而是帮助你把：

- 想法
- 问题
- 知识
- 决策
- 目标
- 行动
- 证据
- 复盘

统一放进一个可视化、可连接、可扩展、可被 AI 理解的图谱系统中。

- 支持
- 反对
- 导致
- 依赖
- 导向

- 证据支持

- 图谱快照读取

- 命令预览

### 学习系统
- 检索练习
- 概念深化

- AI 检查缺口
- AI 补全执行链

## 为什么不是普通思维导图

普通思维导图通常只适合：

- 归纳
- 展示
- 发散

NeuralCanvas 更强调：

- 结构化思考
- 动态更新
- 行动落地
- 证据对抗
- 复盘反馈
- 学习强化
- AI 辅助补全

所以它更像：

> 图谱式认知操作系统  
> 而不只是“导图工具”
