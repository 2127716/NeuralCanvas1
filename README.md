# NeuralCanvas

> 一个把 **知识、任务、决策、复盘、学习强化、AI 补全** 放进同一张图里的 Android 认知图谱系统。  
> 它不是普通思维导图，而是你的 **第二大脑画布**。

---

## 项目简介

**NeuralCanvas** 是一个面向 **学习 / 决策 / 行动落地** 的安卓认知图谱应用。

你可以把它理解成：

- 思维导图
- 知识图谱
- 任务系统
- 决策板
- 复盘系统
- AI 辅助结构补全工具

这些能力的融合体。

它的核心目标不是“画得更花”，而是把你脑子里的内容真正组织成一张：

- 可视化
- 可连接
- 可检索
- 可执行
- 可被 AI 理解
- 可持续迭代

的认知网络。

---

## 它适合做什么

### 学习
- 整理知识网络
- 区分概念 / 例子 / 反例
- 做检索练习
- 做迁移练习
- 形成长期复习闭环

### 决策
- 比较方案
- 记录支持证据 / 反对证据
- 评估风险与准则
- 做轻量决策矩阵
- 跟踪判断更新

### 执行
- 把目标拆成项目 / 任务 / 动作
- 给动作绑定触发条件
- 识别障碍与最小下一步
- 做每周巡检和执行补强

### 复盘
- 每日复盘
- 每周复盘
- AAR 复盘
- 模式归纳
- 经验沉淀

### AI 辅助
- 读取当前图谱
- 补全结构缺口
- 帮你补下一步
- 检查学习链 / 执行链
- 辅助知识导入

---

## 为什么它不是普通思维导图

普通思维导图更偏：

- 发散
- 展示
- 归纳

NeuralCanvas 更偏：

- 结构化思考
- 动态更新
- 行动落地
- 证据对抗
- 学习强化
- AI 可操作图谱

所以它更像：

> **图谱式认知操作系统**  
> 而不只是导图工具

## 核心特性

### 1. 节点式认知图谱

支持多种节点类型，例如：

- 收集
- 概念
- 想法
- 问题
- 资源
- 任务
- 行动
- 目标
- 项目
- 关键结果
- 笔记
- 决策
- 方案
- 准则
- 证据
- 假设
- 风险
- 障碍
- 习惯
- 触发器
- 复盘
- 来源
- 洞察
- 实验

每个节点可承载：

- 标题 / 内容
- 标签
- 优先级 / 状态
- 截止时间 / 复习时间
- 预计耗时 / 实际耗时
- 置信度 / 证据强度
- KR 目标值 / 当前值
- 扩展元数据

### 2. 语义化连线

连线不是“随便画条线”，而是有明确含义的关系，比如：

- 支持
- 反对
- 导致
- 依赖
- 导向
- 归属
- 证据支持
- 证据反驳
- 触发
- 阻碍
- 缓解
- 替代
- 参考

这让图谱能真正承载“认知逻辑”，而不仅是视觉连接。

### 3. AI 图谱助手

项目已经有 AI 图谱链路，支持：

- 图谱快照读取
- 命令生成
- 命令预览
- 执行落图
- 后台巡航
- 知识导入辅助
- 结构补全建议

AI 不只是聊天，而是能基于你的图谱进行结构化操作。

### 4. 科学工作流模板

内置多类模板，可一键生成图谱结构：

#### 执行系统
- WOOP
- If-Then 实施意图

#### 复盘系统
- 每日复盘
- 每周复盘
- AAR

#### 决策系统
- Premortem
- WRAP
- 证据评估
- 决策矩阵

#### 学习系统
- 检索练习
- 迁移练习
- 概念深化

#### 结构补全
- AI 检查缺口
- AI 补全执行链
- AI 补全学习链

### 5. 多模态知识导入

当前已经向多模态输入演进，支持或正在接入：

- 手动文本导入
- 文档导入
- 图片 OCR
- 后台导入处理
- 实时语音转文字（Sherpa-ONNX 方向）
